WGS84 to Minna Datum Transformation

Transformation Parameters (OSGoF Official)

Use these 7-parameter values for Nigeria:

Parameter Symbol Value
Translation X Tx +93.809786 m
Translation Y Ty +89.748672 m
Translation Z Tz –118.837660 m
Rotation X Rx +0.000010827829 rad
Rotation Y Ry +0.0000018504213 rad
Rotation Z Rz +0.0000021194542 rad
Scale S 0.9999939 (≈ –6.1 ppm)

Note: These are the inverse of the Minna→WGS84 parameters, so they convert WGS84 coordinates into Minna Datum.
