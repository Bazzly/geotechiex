📋 Troubleshooting Checklist

1️⃣
Database Credentials:

Open geotechiex.php and update lines 31-34 with your actual database credentials

2️⃣
PHP Version:

Ensure PHP 7.4+ is installed. Run: php -v

3️⃣
File Permissions:

Set correct permissions: chmod 644 geotechiex.php

4️⃣
CORS Headers:

Ensure CORS headers are being sent (they're in the PHP file)

5️⃣
Error Logs:

Check: geotechiex_errors.log in the same directory as the PHP file
